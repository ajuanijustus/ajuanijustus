I'm a doctoral researcher at the University of Birmingham working on multi-agent reinforcement learning: how agents with different abilities learn to communicate, and how they team up with people. Before the PhD I spent three years as a machine learning engineer at Accenture.

### Now

- Getting [GridHunt](https://github.com/ajuanijustus/gridhunt) to 1.0: heterogeneous, mixed-motive predator-prey environments for MARL and human-agent teaming, with a PettingZoo API. `pip install gridhunt`
- PhD work on grounded communication policies for heterogeneous agent teams ([AAMAS 2026](https://doi.org/10.65109/OAYF2008))

### Research code

| | |
|---|---|
| [**GridHunt**](https://github.com/ajuanijustus/gridhunt) | Predator-prey environments for heterogeneous, mixed-motive MARL and human-agent teaming. On PyPI, with docs, tests and IPPO/MAPPO/HAPPO baselines |
| [**voice2mode**](https://github.com/ajuanijustus/voice2mode) | Phonation mode classification in singing with self-supervised speech models. [ICASSP 2026](https://doi.org/10.1109/ICASSP55912.2026.11460695) |
| [**music-gen-hitl-rl**](https://github.com/ajuanijustus/music-gen-hitl-rl) | Music generation with human-in-the-loop reinforcement learning. [IEEE BigData 2023](https://arxiv.org/abs/2501.15304) |
| [**eq2rl**](https://github.com/ajuanijustus/eq2rl) | Single-file RL implementations in PyTorch and JAX that follow the paper equations, written for studying |
